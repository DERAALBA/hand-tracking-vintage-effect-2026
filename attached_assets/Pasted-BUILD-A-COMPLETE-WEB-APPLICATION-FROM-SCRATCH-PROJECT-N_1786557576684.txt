============================================================
1. CORE CONCEPT
============================================================

Create a futuristic experimental real-time webcam experience.

The user sees their live webcam.

The user raises BOTH HANDS.

Four fingertips control a dynamic digital distortion frame.

The four control points are:

P1 = LEFT THUMB TIP
P2 = LEFT INDEX FINGER TIP
P3 = RIGHT INDEX FINGER TIP
P4 = RIGHT THUMB TIP

Connect:

P1 → P2 → P3 → P4 → P1

This creates the distortion frame.

The frame is NOT a normal rectangle.

It must dynamically follow the user's fingers.

It can naturally become:

- rectangle
- trapezoid
- diamond
- rotated quadrilateral
- narrow shape
- wide shape
- irregular shape
- ribbon
- bow-tie
- self-intersecting shape

These unusual shapes are INTENTIONAL.

DO NOT force the four points into a convex hull.

DO NOT sort them around the centroid.

DO NOT "correct" self-intersection.

DO NOT force the frame into a rectangle.

The frame must preserve the natural relationship between the four fingertips.

5. MIRROR / ORIENTATION
============================================================

THIS IS EXTREMELY IMPORTANT.

The webcam is a SELFIE CAMERA.

The visible camera should behave like a mirror.

If the user moves their real hand LEFT:

the hand should visually move LEFT.

If the user moves their real hand RIGHT:

the hand should visually move RIGHT.

The hand tracking coordinates must match the visible mirrored camera.

However:

DO NOT DOUBLE-MIRROR THE DISTORTION TEXTURE.

There are four coordinate systems:

1. Webcam video
2. MediaPipe landmarks
3. Canvas
4. WebGL camera texture / UV coordinates

All of them must be visually consistent.

There must be ONLY ONE intentional horizontal mirror transformation.

DO NOT blindly apply:

x = 1 - x

in multiple places.

DO NOT mirror the video AND then mirror the WebGL texture again unless the rendering pipeline specifically requires it.

6. CRITICAL IMAGE ORIENTATION REQUIREMENT
============================================================

The camera image OUTSIDE the frame and the camera image INSIDE the frame must have EXACTLY THE SAME ORIENTATION.

Example:

If the face outside the frame has orientation A,

the face inside the frame must also have orientation A.

There must never be:

OUTSIDE = normal mirror

INSIDE = reversed mirror.

The distortion effect must NOT accidentally flip the camera texture.

Inspect the WebGL UV mapping carefully.

If the visible video is already mirrored using CSS:

do not automatically mirror the WebGL texture a second time.

The distortion texture must visually match the camera.
